# Бекендът на Plauvia

Всичко, което живее извън браузъра: базата, писмата и настройките, които се
пипат от таблото на Supabase, а не от кода.

Проектът е `gkgpwlbxvqylqarnxglv`. Файловете тук се пускат от
**Supabase → SQL Editor → New query → Run** и всички са безопасни за повторно
пускане — не трият и не пренаписват съществуващи данни.

## Кое в какъв ред

| Файл | Какво прави | Задължителен |
| --- | --- | --- |
| `schema.sql` | Таблицата `records`, кофата `library`, правилата за достъп и изтриването на профил | да, това е основата |
| `usernames.sql` | Уникални потребителски имена | само ако искаш имената да са наистина запазени |
| `security.sql` | Журнал за влизания, резервни кодове, квота за файлове, ограничител | за двуфакторната защита и журнала |

`security.sql` заменя правилото за качване от `schema.sql` с такова, което брои
и обема. Пусни ги в реда по-горе, ако тръгваш от нула.

## Какво прави `security.sql`

**Журнал за сигурност.** Всяко влизане оставя ред — записан от тригер върху
`auth.sessions`, не от приложението. Разликата има значение: ако редовете
идваха от браузъра, някой, влязъл в чужд профил, просто нямаше да изпрати реда
за собственото си влизане. Показва се в Настройки → Сигурност и се пази 90 дни.

**Резервни кодове.** Десет на профил, хеширани с bcrypt. Показват се точно
веднъж. Използването на код не дава втора степен на достъп — то сваля
двуфакторната защита, за да може човекът да влезе с паролата си и да я настрои
наново. Това описва какво наистина се е случило: телефонът го няма.

**Квота.** 2 GB на профил, пазена от правило върху `storage.objects`. Числото е
в `storage_quota_bytes()` — смени го там и важи веднага, без деплой.

**Ограничител.** Таблица и функция `rl_allow()`, използвани от функциите тук.
Важи за тази база; влизането минава през GoTrue и има свои лимити в
Authentication → Rate Limits.

## Писмата

Шаблоните в `emails/` се генерират от `scripts/make-email-templates.mjs` и се
поставят в **Authentication → Emails**:

| Кутия в Supabase | Файл |
| --- | --- |
| Confirm signup | `emails/confirm-signup.html` |
| Magic Link | `emails/magic-link.html` |
| Reset Password | `emails/recovery.html` |
| Change Email Address | `emails/email-change.html` |
| Reauthentication | `emails/reauthentication.html` |
| Invite user | `emails/invite.html` |

Първите пет носят `{{ .Token }}` — шестцифрен код, не връзка. Това е нарочно:
приложението иска код и на трите места, където пита. Ако някой шаблон бъде
върнат към `{{ .ConfirmationURL }}`, съответният екран спира да работи.

За да ги пресъздадеш след промяна на марката:

```bash
node scripts/make-email-templates.mjs
```

## SMTP през Resend

Вграденият подател на Supabase праща по няколко писма на час. Достатъчно е за
проба и напълно недостатъчно за публичен сайт — затова кодовете нямат смисъл,
докато това не е направено.

1. **resend.com** → Domains → Add Domain → `plauvia.com`
2. Resend показва три записа. Сложи ги както са ги дал, без да ги съчиняваш:
   - `TXT` за SPF
   - `TXT` за DKIM
   - `TXT` за DMARC (`_dmarc`), ако го предлага
   Записите се въвеждат там, където се управлява DNS-ът на домейна.
3. Изчакай Resend да покаже домейна като потвърден.
4. Resend → API Keys → нов ключ с права само за изпращане.
5. **Supabase → Project Settings → Authentication → SMTP Settings**:

   ```
   Host      smtp.resend.com
   Port      465
   Username  resend
   Password  ключът от стъпка 4
   Sender    no-reply@plauvia.com
   Name      Plauvia
   ```

6. Прати си пробно писмо от Supabase и виж дали идва.

## Настройки, които се пипат на ръка

**Authentication → Sign In / Providers**

- **Confirm email** — включи го. В момента е изключено, което значи, че всеки
  може да се регистрира с чужд адрес и профилът се активира веднага. Включвай
  го чак след като SMTP работи, иначе хората ще се регистрират и няма да
  получат нищо.
- **Google** — включен. Callback адресът трябва да е
  `https://gkgpwlbxvqylqarnxglv.supabase.co/auth/v1/callback` и същият да стои в
  Google Cloud Console → Credentials.

**Authentication → URL Configuration**

```
Site URL   https://www.plauvia.com
```

**Authentication → Multi-Factor** — TOTP трябва да е разрешено, за да работи
Настройки → Сигурност.
